# SmartBudgetManagger
A project for managing Budget.
                      README — SmartBudget Manager
What It Does
•	Tracks income and expenses
•	calculates totals and monthly balance
•	summarizes spending by category
•	compares expenses with budgets
•	displays a chart, and indicates budget status.
Workbook Contents
•	Dashboard: Displays totals, budget summary, status, and chart.
•	Transactions: Enter transaction details.
•	Categories: Contains predefined expense categories and monthly budget values.
Requirements
•	Microsoft Excel 2016, 2019, 2021, Microsoft 365, or compatible spreadsheet software.
•	Keep a backup copy before editing.
Quick Start
1.	Open SmartBudget_Manager.xlsx.
2.	In Transactions, enter the date and description.
3.	Choose Income or Expense.
4.	Enter an amount in the relevant column. For expenses, select a category.
5.	Review budgets on Categories.
6.	Check the Dashboard.
7.	Save the workbook.
Important Notes
•	Do not overwrite the automatically calculated Month column.
•	The supplied file includes sample transactions and default budgets.
•	Formulas are prepared for transaction rows 4–50. Verify formulas before adding more rows.
•	This workbook is a basic tracker, not accounting software.
